# java-movie-precourse

도메인

1. 고객: 이름, 포인트, 예매

2. 영화: 제목, 러닝 타임

3. 상영: 영화, 영화관, 시작 시간, 예매된 좌석

4. 좌석: 좌석 위치, 등급

5. 예매: 고객, 예매 정보(상영, 좌석 정보), 결제 정보, 최종 가격

6. 영화관: 영화관 이름, 운영 시간

기능 목록

1. 도메인 추가하기

2. 단일 상영 예매 로직 구현

3. 다중 로직 예매 로직 구현

4. 총 결제 금액을 계산

    - 좌석 등급에 따른 기본 금액 계산

    - 무비데이 할인 적용

    - 조조/심야 할인 적용

    - 보유 포인트 차감

    - 결제 수단에 따른 추가 할인 적용

    - 결제를 통해 예매를 확정하고 좌석 상태를 갱신
